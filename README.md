# MiGallerySync

一个将**小米相册云备份目标**从「小米云」无缝替换为**自建 WebDAV** 的 LSPosed 模块。

相册原生的云备份、空间优化、下载原图等体验均保持不变，区别仅在于：数据不再上传至小米云，而是存入你完全掌控的 WebDAV 服务器。

## 核心功能

- **备份无缝接管**：支持「仅传 WebDAV」、「双写（同时备份至小米云）」以及「关闭（不介入）」三种工作模式。
- **原生空间优化**：在相册中触发「空间优化」后，原图自动上传至 WebDAV，本地仅保留轻量缩略图；随时点击照片即可「下载原图」恢复。
- **保留完整元数据与原格式**：EXIF 信息（拍摄时间、GPS、相机参数）、ICC 色彩配置文件完整保留；HEIC 格式优化后依然保持原格式，遇元数据写入异常时优先保护原图。
- **拒绝脏数据上云**：本地生成的缩略图/预览图绝不上传远端，WebDAV 端始终保持纯净的原图与原视频。
- **视频空间优化**：本地仅保留视频封面，原视频存放在远端，点播时支持按需流式拉取。
- **数据完整性保障**：上传/下载均校验文件大小与哈希值（Checksum），校验失败的文件绝不落盘、不上云；遇到任何异常自动回滚至相册原生逻辑，避免两头落空。
- **自定义远端路径**：支持按相册分类（`DCIM/Camera/xxx.jpg`）、按拍摄时间（`2026/09/xxx.jpg`）或全部平铺存放。
- **直观进度管理**：内置进度看板，可实时查看传输队列、速度与远端存储容量。

## 环境要求

| 项目       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| **框架**   | LSPosed（libxposed API 102），作用域勾选 `com.miui.gallery`  |
| **相册**   | MIUI / HyperOS 自带相册（已在 HyperOS 3 / Android 16 实测通过） |
| **服务端** | 任意兼容 WebDAV 协议的服务（Alist、Nextcloud、OpenList、群晖等） |

> *注：新系统若出现相册私有 API 变动，可能会导致功能失效，升级相册版本时请留意。*

## 安装与配置

1. 安装模块 APK。
2. 在 LSPosed 管理器中启用模块，并确认勾选作用域「相册」。
3. 强行停止相册应用后重新打开。
4. 打开系统相册 → 设置 → **MiGallerySync** → 填写服务器地址、账号密码及远端根目录 → 点击「测试连接」。

## 使用建议

- **首次使用**：建议先选取少量照片进行备份与「空间优化」测试，确认远端文件完整无损、可正常「下载原图」后，再批量开启。
- **释放本地空间**：在相册中批量勾选照片 → 点击「空间优化」（原图进 WebDAV，本地留预览图）。
- **恢复原图**：全屏点开照片 → 点击左下角「下载原图」。
- **模式提示**：设为「仅传 WebDAV」后，相册原生的「云端网页查看」等小米云专有功能将不再可用。

## 详细参数说明

| 配置项           | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| 备份模式         | 替换（仅 WebDAV）/ 双写（WebDAV + 小米云）/ 关闭             |
| 远端目录结构     | 按相册分类 / 按时间归档 / 根目录平铺                         |
| 仅限 Wi-Fi 备份  | 开启后，处于移动数据网络时暂停传输                           |
| 保留完整元数据   | 优化与下载时保留 EXIF 参数（时间、位置、光圈快门等）         |
| 维持 HEIC 格式   | 开启后 HEIC 优化依然为原格式；关闭则降级转换为 JPEG          |
| 并发上传数       | 1–8 线程（默认 3）                                           |
| 单文件体积上限   | 超过设定大小的文件自动跳过备份                               |
| 忽略远端同名文件 | 匹配到同名文件直接跳过（可省流量，但不比对文件哈希差异）     |
| 重置备份状态     | 远端文件误删但相册显示「已备份」时，可强制清除标记并重新上传 |
